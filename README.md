## 1. Project Description

The Campus Smart-Parking System is a Java-based application designed to manage vehicle parking in a multi-level university parking facility.

The system manages vehicle entry and exit, parking slot allocation, ticket generation and parking fee calculation.

It uses object-oriented programming concepts to make the application organized, reusable and easy to maintain.

## 2. Objectives

- Identify the objects and classes required for a parking management system.
- Select suitable data structures to represent parking slots.
- Implement parking slot allocation and release.
- Calculate parking fees based on vehicle type and parking duration.
- Apply constructors, static members and inheritance.
- Implement method overriding, polymorphism and abstraction.
- Use interfaces, packages and access modifiers.
- Test and improve the system based on changed requirements.
